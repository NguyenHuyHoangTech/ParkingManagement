The **PBMS IoT Simulator** is an essential development and verification tool that replicates physical parking garage hardware. It allows engineers, QA testers, and evaluators to test end-to-end operational workflows without requiring physical barriers, cameras, loop detectors, or RFID readers.

---

## 🎯 Simulated Hardware Components

1. **Automatic Barrier Gates (Gate In & Gate Out)**:
   - Emulates barrier open/close signals, arm status feedback, and safety sensor states.
2. **RFID Card Readers**:
   - Simulates card taps, card UID transmission, invalid card rejections, and monthly pass card detection.
3. **Automated Number Plate Recognition (ANPR) Cameras**:
   - Simulates camera vehicle capture, mock OCR confidence ratings, and capture image upload payloads.
4. **Ultrasonic Bay Occupancy Sensors**:
   - Emulates individual slot presence detection (occupied/vacant) with real-time state telemetry.
5. **Smart Routing LED Display**:
   - Simulates lane directional signs that display real-time zone guidance generated by the backend routing engine.

---

## 🚀 Running the Simulator

```bash
# Navigate to simulator directory
cd pbms-iot-simulator

# Install dependencies
npm install

# Run simulator
npm run dev
```

The simulator runs by default at `http://localhost:3001` (or next available port).
Ensure `pbms-be` is running on `http://localhost:8080` to receive simulated hardware events.
